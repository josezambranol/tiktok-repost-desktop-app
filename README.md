# TikTok Auto Unrepost - Aplicación de Escritorio 🖥️

Aplicación independiente con interfaz gráfica moderna (Dark Theme) para eliminar de forma automática y visual todos los compartidos (*reposts*) de TikTok.

---

## ✨ Características de la App

- **Interfaz Gráfica Moderna:** Fondo oscuro con acentos neón estilo TikTok, sin necesidad de usar la consola negra.
- **Botón "1. Abrir Navegador":** Abre Google Chrome con protecciones anti-detección para que inicies sesión cómodamente.
- **Controles en Vivo:**
  - **▶ Iniciar:** Arranca el ciclo continuo (pulsar botón amarillo $\rightarrow$ bajar con flecha $\vee$ $\rightarrow$ repetir).
  - **⏸ Pausar / Reanudar:** Pausa al instante para que revises el navegador o esperes, y reanuda con un clic (o con la tecla `P` o barra espaciadora).
  - **🔄 Reiniciar:** Desatasca o reinicia la lectura sobre el video actual (tecla `R`).
  - **⏹ Detener:** Frena la limpieza sin cerrar el navegador.
- **Control Deslizante de Velocidad:** Ajusta la pausa entre videos desde **0.4s (Turbo)** hasta **3.0s (Seguro)**.
- **Registro en Vivo (Log):** Muestra cada acción segundo a segundo con colores y marcas de tiempo.
- **Estadísticas en Tiempo Real:** Contador grande de videos eliminados y omitidos.

---

## 🚀 Cómo Ejecutarla

- **Opción 1:** Haz doble clic en **`run_app.bat`** en esta carpeta.
- **Opción 2:** Ejecuta **`crear_acceso_directo.bat`** para tener un icono de acceso directo directamente en tu **Escritorio de Windows**.
- **Opción 3 (Desde terminal):**
  ```powershell
  python app.py
  ```
